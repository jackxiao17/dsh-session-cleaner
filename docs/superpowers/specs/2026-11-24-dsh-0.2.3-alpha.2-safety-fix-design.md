# dsh-session-cleaner 0.8.0 安全修复设计

日期：2026-11-24  
目标宿主：DeepSeek Harness 0.2.3-alpha.2

## 目标

1. 默认 JSONL + zstd + 默认 JSON storage 的冷会话删除、恢复、彻底删除保持可用。
2. 消除实时 Agent、活动子代理、定时任务和存储后端导致的数据安全风险。
3. 明确支持边界，遇到未知后端或 live Agent 时 fail closed。
4. 升级插件版本至 0.8.0，更新文档、验证台与发行清单。
5. 完成自动化回归、真实宿主集成验证和最终复查。

## 非目标

- 不实现 DSH 宿主级 `AgentHandle.dispose(id)` API。
- 不通过私有 AgentLoop 内部结构强行销毁实时 Agent。
- 不支持 SQLite Session provider 或自定义 sessions/storage root；这些配置必须明确拒绝。
- 不改变回收站 30 天保留期和批量操作交互。

## 安全不变量

- 任何 live Agent 会话不得进入回收站；返回 409，且不取消、不 detach、不移动文件、不清缓存。
- 只有 `agents.get(id)` 与 `sessions.get(id)` 都不存在时才允许冷会话删除。
- 移入回收站不得永久删除定时任务；活动任务暂停，恢复时恢复，彻底删除时才删除。
- 非 JSONL 或无法验证的存储位置不得继续清理。
- 冷会话不得伪造 `session/disposed` 事件。
- 子代理关系必须同时满足 `origin === 'subagent'` 与 `parentSession`；超过安全深度明确失败。
- 所有破坏性操作前重新验证后端、路径与 header 身份。

## 实施方案

### Host 生命周期

- 用 `assertColdSession(sessionId)` 替代 `teardownLive()` 的主动拆除行为。
- 删除入口在捕获快照前检查 live Agent/Session；存在即抛出 `session-active`。
- 彻底删除回收站项时不需要 live teardown，因为进入回收站前已保证冷会话。

### 定时任务

- 新增 `pauseSessionSchedules(sessionId)`：对 active 行调用公开 `schedule.edit({id, action:'update', patch:{active:false}, expectedUpdatedAt})`。
- 快照记录暂停前状态与 `updatedAt`。
- 新增 `resumeSessionSchedules(snapshot)`：仅恢复本插件暂停且仍匹配 `expectedUpdatedAt` 的任务，避免覆盖用户后续修改。
- `purgeSessionSchedules()` 继续使用公开 `edit({id, action:'delete'})`，不再依赖私有 `stopSessionTasks`。
- 暂停失败时删除操作失败并回滚快照/文件阶段，不得把任务永久删除。

### 存储后端

- 可选注入 `sessionPersistence`。
- 删除前调用 `stat(id)`，要求 `location.kind === 'jsonl'`，且路径位于已验证的 sessions root 下。
- 默认 root 与 `dshHomePath('sessions')` 不一致时 fail closed。
- SQLite、未知 provider、缺失 location 或路径不一致均返回 `unsupported-backend` / `backend-path-mismatch`。

### 数据校验

- v4 header 至少验证 `type/version/id/createdAt/isSeeded/delegationDepth` 与 cwd 类型。
- 子代理遍历保留 origin 条件，使用 cycle-safe 遍历；超过 32 层明确报错。
- 移除冷会话 `{id}` 形式的 `session/disposed` 补发。

### Client

- live 会话删除时展示明确错误：“请先结束并关闭会话，或等待会话空闲后再删除”。
- 菜单顺序文案改为“归档之前”。
- footer slot 改为自宽，面板配色改用宿主 alias tokens。
- 保留现有 primitives baseline 依赖，因为当前宿主明确支持且运行中已激活。

### 版本与文档

- `package.json` 与 `lib/index.js` buildId 升级为 0.8.0。
- Node 引擎范围与 0.2.3-alpha.2 对齐为 `^24.22.3 || >=26.13.1`；DSH 最低支持版本收紧为 `>=0.2.3-alpha.2 <0.3.0`，旧版真机兼容测试暂不开展。
- 更新 README、英文 README、locale 描述与详情，说明仅支持冷会话和默认 JSONL。
- 发行包加入 `screenshots.json` 与 `assets`。

## 测试策略

### 先写失败测试

1. live Agent 删除返回 409，不调用 cancel/scope.dispose/store.delete。
2. live Session（无 Agent）同样拒绝。
3. 活动子代理不会在父会话冷删除时被误拆；关系校验覆盖 origin 与超深树。
4. trash 暂停任务而不删除；restore 恢复；purge 才删除。
5. SQLite/未知 location/自定义 root fail closed。
6. 冷会话不 emit `session/disposed`。
7. 完整 v4/zstd 冷会话删除→恢复→彻底删除回归。
8. Client 注册、文案、主题 token 与菜单顺序静态断言。

### 自动化验证

- `node --check lib/index.js`
- `node --check lib/client.js`
- `node scripts/verify.mjs`
- manifest / exports / 打包文件清单检查
- 当前宿主 `cordis_inspect` 契约检查

### 真机验证

- 使用专用测试会话，不触碰现有会话。
- 验证删除→恢复→再次删除→彻底删除。
- 检查侧栏、回收站、工作区记账、置顶/归档、投影缓存、定时任务与文件残留。
- 验证 live 会话被安全拒绝且文件/缓存/任务均未变化。
- 清理测试会话、回收站项和临时目录。
